## Assignment 1: Internet vs. World Wide Web
The Internet and the World Wide Web are often used interchangeably, but they are not the same thing. The Internet is the global infrastructure—a network of networks that connects billions of devices using protocols like TCP/IP. It was born from ARPANET in 1969 and became the modern Internet in 1983 when it adopted TCP/IP. The Internet carries many services: email, file transfer, VoIP, and the Web.

The World Wide Web, on the other hand, is one service that runs on top of the Internet. It was invented by Tim Berners‑Lee in 1989 at CERN. The Web is a collection of web pages linked together and accessed through browsers using HTTP or HTTPS. While the Internet is the roads and cables, the Web is like the shops and signs you visit along those roads.

Key differences: the Internet uses TCP/IP; the Web uses HTTP/HTTPS. The Internet existed before the Web and includes email, FTP, and more. The Web is just one way to share information over the Internet. In short, the Internet is the infrastructure; the World Wide Web is a service that makes the Internet easy to browse.

## Assignment 2: Web 3.0
Web 3.0 is the next envisioned phase of the web. While Web 1.0 was read‑only (static pages) and Web 2.0 is read‑write (social media, user‑generated content), Web 3.0 aims to be read‑write‑own. It focuses on decentralisation, where users control their data and digital assets.

Technologies powering Web 3.0 include blockchain, smart contracts, and dApps (decentralised applications). Cryptocurrencies and NFTs are early examples. The idea is to remove central platforms like Facebook or Google and let users interact peer‑to‑peer. Another interpretation, from Tim Berners‑Lee, is the Semantic Web—where machines understand data meaningfully.

In my opinion, Web 3.0 is still experimental. Blockchain has real potential for ownership and transparency, but it faces challenges: scalability, energy use, and usability. Most everyday users don’t yet see a clear benefit. I believe elements of Web 3.0—like digital identity and decentralised storage—will gradually blend into the current web rather than replace it completely. Its future depends on solving real problems, not just hype.
